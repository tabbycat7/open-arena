# 1 教学系统整体描述

我想构建一个多智能体的系统，这个系统的功能是：生成教案，但是我的教案是这样，我将课堂教案结构化建模为教学地图。教学地图由节点、边以及边权构成，其中：教学目标被拆解为相互关联的教学任务，以课堂问题的形式存储于节点中；教学逻辑关系隐含于图的边之中。为了更好地适应班级的学情，我在教学地图中设置了三类节点，分别为：

 - （1）主干问题节点：针对学优生设计，难度较高，考察学生“评价”和“创造”的认知能力。
 - （2）变式问题节点：针对主干问题进行一系列变式，通过变换设问情景激发学生的学习兴趣，调动学生的课堂积极性。
 - （3）支架问题节点：针对学困生设计，难度中等偏低，考查学生记忆、理解、应用及分析的认知能力。其通过设问串联两个相关联的知识点，起到“承上启下”的功能。
 
 问题之间的连接关系为先逐步生成一系列主干问题，这些问题依据教学逻辑相互连接构成问题链，该问题链形成的教学路径可以逐步引导学生达成教学目标。在完成主干问题链的构建之后，针对链上的每一个主干问题，利用大语言模型生成若干变式问题，这些问题与主干问题相连。此外，同样针对链上的每一个主干问题，同时考察其与上一个主干问题之间的知识点关联，利用大语言模型生成若干支架问题，这些问题位于两个主干问题之间，构成了连接二者的“桥梁”。
