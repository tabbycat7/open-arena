方程的根与函数图象的交点

思考： 当水平直线 y = a 随着参数 a 的减小，恰好落到折线“槽谷”的底部（即 a = 2）时，直线与折线呈现出怎样的位置关系？此时方程的实数解有几个？
无数个交点！
动态调整参数 a
直线高度 y = a 2.0
代数验证：当 x 取区间 [-1, 1] 内的值时
当 x = 0 时: |0+1| + |0-1| = 1 + 1 = 2
当 x = 0.5 时: |0.5+1| + |0.5-1| = 1.5 + 0.5 = 2
当 x = -0.8 时: |-0.8+1| + |-0.8-1| = 0.2 + 1.8 = 2
任意 x ∈ [-1, 1]: (x+1) + (1-x) ≡ 2
