代数纠错诊所

观察小明对 $y = |x-1| + |x+1|$ 在 $x < -1$ 时的化简过程，找出其中的代数符号错误：

当 $x < -1$ 时，
$y = $ -x-1 $ - x + 1 = -2x$

💡 提示： 当 $x < -1$ 时，代数式 $(x-1)$ 的正负性如何？去掉绝对值符号时，是否正确应用了分配律？

🔍 符号诊断报告

当 $x < -1$ 时，$x-1 < 0$，因此：
$|x-1| = -(x-1)$

注意负号分配给括号内的每一项！

区间边界“不重不漏”探究

调整下方等号的归属，观察数轴上边界点 -1 的定义状态：

左侧区间包含边界 ($x \le -1$)
右侧区间包含边界 ($x \ge -1$)
边界点重复定义！这会导致该点处函数值被重复计算，不符合分段函数的定义规范。
思考与讨论： 1. 为什么 $|x-1|$ 去掉绝对值后是 $-(x-1)$ 而不是 $-x-1$？这反映了什么代数运算易错点？
2. 若在两个区间都写了等号（即 $x \le -1$ 且 $x \ge -1$），虽然函数在 $x=-1$ 处连续且值相同，但在逻辑上和分段函数的严格定义上存在什么问题？
